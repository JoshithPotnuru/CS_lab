01 — THE INTENDED TASK
Export a thumbnail.
A creator uploads a photo, selects a width and saves a PNG. The server calls ImageMagick to resize the image, optionally apply grayscale, and write the export.

    
02 — THE ROOT CAUSE
A filename becomes shell syntax.
With postcard.png; id, ImageMagick first writes the image. The shell then interprets the semicolon and runs id. Its real uid/gid output appears in the response: in-band command injection.

    
03 — THE IMPLEMENTED FIX
Keep filenames as data.
The secure path allows only a simple PNG basename and runs ImageMagick directly with shell=False. The same injected filename is rejected before processing. Without a shell, separators cannot launch another command.

  


  
Defense notes & a short viva walkthrough
    
Avoid the shell: use a native image library such as Pillow for resizing instead of starting a command-line program. Parameterized execution: keep the executable fixed and send separate arguments; never invoke sh -c. Allow-list validation: permit only the filename, format and dimensions the application needs; reject paths and options. Least privilege: run the converter as a dedicated unprivileged user to limit damage. This does not remove an injection flaw. Character blacklists miss other shell operators and substitutions.
