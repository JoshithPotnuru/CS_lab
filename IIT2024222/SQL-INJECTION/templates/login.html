How it works

{% if vul %}
Flawed code
query = "SELECT * FROM users WHERE username = '"
        + username + "' AND password = '" + password + "'"
Root cause: input is concatenated into the SQL text, so an attacker can close the string literal and rewrite the query's logic (CWE-89).
{% else %}
Fixed code
query = "SELECT * FROM users WHERE username = ? AND password = ?"
db.execute(query, (username, password))
Why it works: the query structure is fixed before any input arrives. The driver sends values separately, so input can never change the query's grammar.
